# AI社員（無料版）｜話しかけるのは、秘書1人だけ

Claude Code に入れて使う「AIの会社」です。
あなたが話しかけるのは秘書だけ。秘書が担当に仕事を振り、点検係が読んでから、あなたに届きます。

無料版には、秘書室の4人がいます。

| 担当 | やること |
|---|---|
| 秘書 | 話を聞いて、担当に振り、まとめて報告 |
| リサーチ係 | 調べて、出どころつきでまとめる |
| ライター係 | 文章の下書き |
| 点検係 | 読む人の立場で、事実・AIっぽさ・抜けを点検 |

## 使い方（3分）

1. 右上の緑の「Code」→「Download ZIP」でダウンロードして、展開する
2. Claude Code で、そのフォルダを開く
3. 「はじめまして。今日からよろしく。」と話しかける

くわしい入れ方（画面つき）：https://note.com/keita_aiwork/n/nedb1014fd422

## 普通にAIを使うより良い所

- 毎回「あなたは〇〇のプロです」と説明しなくていい
- 頼み方を考えなくていい（秘書が担当を選ぶ）
- 書いたAIと直すAIが別（自分の文を自分でチェックしない）
- 結果がファイルに残る（次の日に続きから頼める）
